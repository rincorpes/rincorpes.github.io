STUDIO / PRIVATE SOFTWARE

Less time coordinating tools. More time building.

A guarded operation should leave a reviewable trail: what ran, why it ran, how long it took, and which evidence it produced. Studio explores that workflow as local developer infrastructure.

Private source. No internal configuration, logs, or unreviewed screens are published here.

ENDR / PRIVATE RESEARCH

What happens when the world keeps moving?

Knowledge lookup and a chat loop are relatively straightforward. Navigation, interruptions, and unreliable world state are harder. Endr explores those boundaries with real bounded actions and measured failure cases.

Private R&D. Global navigation and autonomous gameplay are not presented as solved.
