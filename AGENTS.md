## Scope

## Purpose

This directory is the personal website and portfolio site.

## Working Rules

- Treat this directory as its own web project.
- Work from local HTML, CSS, JavaScript, and assets in this repo only.
- Preserve a clean static-site structure unless the user explicitly wants a
  larger frontend stack migration.
- Keep changes easy to preview locally and safe to publish.
